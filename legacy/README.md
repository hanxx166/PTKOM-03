# Versi lama (arsip)

Website vanilla `index.html` + `app.js` + `api/*.php` (penyimpanan file JSON).
Dipertahankan sebagai pembanding migrasi. Versi aktif sekarang:

- Frontend: `../frontend/` (Vite + Tailwind React)
- Backend: `../backend/` (Express + Prisma)
- Database seed: `../backend/prisma/seed-data.json` (disalin dari `data/content.json` sebelum dipindah)

Jalankan versi lama (butuh PHP): `php -S localhost:8000` dari folder ini.
